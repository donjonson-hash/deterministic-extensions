Перед запуском проверок
Выполняются команды, выбранные при запуске локального сервера. Они запускаются во временной копии проекта с правами вашей учётной записи. Временная копия не является песочницей. Запускайте проверки только для кода, которому доверяете.

      
Drydock: весь снимок проекта

Проверки не должны создавать или менять файлы в копии проекта. Зависимости из node_modules не копируются. Обычные команды тестов необязательны. Если подключён Drydock, его отчёт и подтверждение просмотра обязательны.

Работает локально, без LLM и платных AI API. Для начала нужен Git-проект без несохранённых изменений. Пилот управляет одной задачей за сессию; для следующей задачи запустите новую сессию.
