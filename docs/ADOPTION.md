# План внедрения

## 1. Самостоятельная база — v0.1.0

Зафиксированы контракт, ограничения, чистые операции, контроль асинхронных результатов, шаблон и воспроизводимая упаковка. Это демонстрационная реализация общих принципов, а не механический перенос всех функций двух продуктов.

Материал для выделения принципов:

- Code Compare Local, локальный снимок `e8b69667854391c8cd3998a66b90349c465715d8`: байтовое сохранение, версии документов, одноразовые команды, Undo/Redo, canonical full diff. Движок CodeMirror и его сборочные патчи не перенесены.
- Compare These Texts, локальный снимок `f921422b4e49800e7599c0a628a183f333ab6c1e`: локальная обработка, пакетные проверки, жизненный цикл интерфейса и отдельные правила постоянного хранения. IndexedDB и синхронизация вкладок не перенесены.

## 2. Адаптер Code Compare Local — следующий отдельный PR

Выбрать один модуль: документы/UTF-8 или контроль актуальности worker. Сначала прогнать одинаковые эталонные входы через старую и новую реализации. Сохранить канонический движок сравнения и правила переноса блоков проекта. Пример полного Use A нельзя подставлять вместо блочного переноса.

Критерий: текущие тесты продукта проходят; идентичные входы дают те же байты и отчёты; stale/replay не меняют состояние. Выпускать без добавления новых пользовательских функций в этом PR.

## 3. Адаптер Compare These Texts — отдельный PR

Отделить вычисление и формат документа от сохранения черновиков. Сохранить существующий протокол владения/версий записей IndexedDB и межвкладочные транзакции. Gate для worker не заменяет транзакцию хранилища.

Критерий: воспроизводимые результаты, сохранность черновиков, предсказуемое разрешение конфликта двух вкладок и прежние правила срока хранения. В этой базе постоянного хранения пока нет.

## 4. Расширение общей системы

После успешного внедрения в оба продукта можно вынести стабильное ядро в версионируемый пакет, добавить контракт локальной диагностики Python/JavaScript и другие UI-адаптеры. До этого источник истины — этот репозиторий с зафиксированными версиями; обновления в продукты переносятся явными PR.

Интеграции GPT/Claude/Gemini могут использовать то же локальное ядро. Наличие такого адаптера не должно требовать платной модели для базовых операций.

## Приёмка каждого изменения

- Обозначены входы, политика и представление результата.
- Исходные данные и нормализованное представление разделены.
- Ошибка не приводит к частичному изменению.
- Старые действия и ответы отклоняются после смены ревизии/контекста.
- Повтор, Undo/Redo и байты выгрузки проверены для затронутых операций.
- Обновлены версия и документация, если изменился контракт.
- Проверен реальный пакет расширения; локальная страница отдельно обозначена как ограниченная проверка.
