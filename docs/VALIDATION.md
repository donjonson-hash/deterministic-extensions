# Проверка v0.1.0 — 20 октября 2026

- Node.js 24.19.0: 11 проверок инвариантов прошли.
- Сборка: manifest, локальные ресурсы, синтаксис JS, состав ZIP, SHA-256 и повторяемость байтов при другом порядке входов проверены.
- Chromium 138: сценарий интерфейса прошёл в режиме `local-page`. Проверены исходные и изменённые байты загрузок, повтор Use A, Undo, повтор старой команды после Undo, Redo, Download B, отдельная вкладка справки, работа офлайн и ширина 375 px. Необработанных ошибок и внешних HTTP-запросов не обнаружено.
- Локальная среда Chromium 138 не загрузила расширение; первая установка и событие `onInstalled` этим запуском не подтверждены. CI требует настоящий service worker расширения (`REQUIRE_EXTENSION=1`) и не допускает переход к локальной странице.
- Генератор: создан отдельный проект `sample-extension`; его сборка и пакетные проверки прошли.
- Загрузка Chromium 151 в текущую среду не удалась: получен повреждённый/неполный архив. Поэтому установленное расширение здесь не проверено.
- GitHub Actions ещё не запускался для этого нового репозитория. Его статус нельзя считать зелёным до размещения и выполнения workflow.

Тесты подтверждают перечисленные сценарии, а не универсальную корректность для любых входных данных. Проект является стартовой системой; магазинная публикация и миграция двух существующих продуктов не выполнены.
