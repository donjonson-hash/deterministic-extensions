# Проверка v0.2.0 — 21 октября 2026

- Node.js 24.19.0: все 35 тестов проходят (14 тестов ядра/UTF-8, 20 Git-сценариев, 1 HTTP-сценарий).
- Проверены целый снимок проекта, связанные правки, неизменность исходных файлов/index, стабильный digest/commit, отказы при устаревании, конфликтах и изменении кандидатных файлов.
- Проверки с ошибкой, отсутствующей командой, изменением файлов и зависанием блокируют публикацию. Реальный deadline 30 секунд проверен.
- HTTP: ключ сессии, Origin и устаревшая вкладка проверены; публикация чужого актуального digest не допускается со старым digest.
- Оба ZIP проверены на точный состав, SHA-256 и повторяемость байтов. CLI запускается из распакованного project ZIP без npm-зависимостей.
- Chromium 138: браузерный сценарий запускает демо из распакованного project ZIP, импортирует JSON, показывает три файла, выполняет тесты, создаёт ветку, отменяет и восстанавливает тот же коммит. Исходные рабочие файлы и ветка остаются прежними; ошибок страницы нет.
- Новый project UI является локальной страницей с Node-сервером. Это не тест установленного расширения.
- GitHub CI отдельно требует настоящий установленный MV3-пример (`REQUIRE_EXTENSION=1`) и сценарий project UI. Результат конкретного PR смотрите в его Checks.

Подтверждена работа на Linux. Windows/macOS и установка будущего браузерного адаптера этой проверкой не подтверждены. Это пилот управления изменениями, а не универсальная проверка правильности программ.

## Исторический протокол первоначальной v0.1.0

Тесты подтверждают перечисленные сценарии, а не универсальную корректность для любых входных данных. Проект является стартовой системой; магазинная публикация и миграция двух существующих продуктов не выполнены.
