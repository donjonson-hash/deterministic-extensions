# Шаблон расширения

`template/` — самостоятельная оболочка Chrome Manifest V3 без API-разрешений,
доступа к сайтам, сетевых запросов и LLM. Сборка копирует её в `dist/extension/`,
а модули `src/core/` — в `dist/extension/core/`. Загрузите эту папку через
`chrome://extensions` → режим разработчика → «Загрузить распакованное расширение».

Welcome page открывается только при первой установке. Иконка расширения
открывает `app.html`; Getting started открывает инструкцию отдельно. Интерфейс
английский. Пользовательские документы не записываются в постоянное хранилище.

## Что демонстрирует пилот

1. Выберите A и B: UTF-8 с необязательным BOM, до 1 MiB на файл, с дополнительными
   лимитами текста и истории из ядра. Невалидный UTF-8 отклоняется.
2. Модульный Worker сравнивает текущие документы по индексу строки.
   Это пример фиксированной политики `line-index-v1`, а не алгоритм минимального
   diff: вставка строки может показать много последующих отличий.
3. Use all of A in B применяет заранее подготовленную неизменяемую команду.
   Старая кнопка несёт старую команду: повтор не переносится на новые документы.
4. Undo/Redo восстанавливает точные данные B, включая смешанные переводы строк
   и BOM. Use all of A копирует весь A вместе с BOM.
5. Download B кодирует текущий raw-документ в UTF-8; результат не берётся из
   визуального textarea. Имя скачивания фиксировано: `reviewed-b.txt`.

В textarea отображается LF-нормализованный текст. Пока пользователь не вводит
изменения, это не меняет исходные байты. Явное ручное редактирование B использует
LF во всём B и сохраняет его BOM; уведомление сообщает об этой границе.
Названия выбранных файлов — только метаданные оболочки: подпись Last opened не
является частью истории документа и не определяет скачиваемые байты.

## Асинхронные границы

- Каждая сторона имеет собственный gate загрузки файла. Поздний результат
  старого выбора файла не заменяет более новый выбор или правку этой стороны.
- Gate Worker получает текущую ревизию и канонически сериализованную политику.
  Старые результаты не показываются после правки, Undo/Redo или смены политики.
- Core не знает DOM, Blob, Worker, имён файлов и таймеров. Таймер освобождает
  URL скачанного Blob; он не участвует в сравнении или формировании байтов.
- Текст файлов выводится через textContent/value; содержимое не исполняется.

На экран выводятся первые 100 изменённых позиций с общим количеством и кнопками
Show line. Оба полных текста остаются в редакторах. Проверка синтаксиса,
выравнивание перемещённых строк, редактирование A, долговременное хранение,
магазинная локализация и интеграция с GPT/Claude/Gemini в этот шаблон не входят.
